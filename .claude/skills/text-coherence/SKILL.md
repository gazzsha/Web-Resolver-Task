# Связность и логика научного текста: чек-лист рецензента

Различай: **когезия (cohesion)** — связь на уровне предложений (повторы, отсылки, связки); **когерентность (coherence)** — связь идей на уровне смысла. Проверяй оба уровня.

## 1. Поток «старое → новое» (given-new)
Каждое предложение лучше начинать с уже известной читателю информации (тема), а новое выносить в конец (рема). Флаг: абзац, где новое понятие вводится без «мостика» от предыдущего; резкая смена темы без связки.

## 2. Связки и переходы (transition signals)
Связка должна ТОЧНО отражать логическое отношение: причина («поскольку», «так как»), следствие («следовательно», «поэтому»), противопоставление («однако», «в отличие от»), уступка («хотя», «несмотря на»), добавление («кроме того»). Флаг: связка не соответствует отношению (ложное «следовательно»), либо переходов нет вовсе (абзацы «встык»).

## 3. Противоречия между частями (главный источник ошибок)
Сверяй одно и то же утверждение/число/термин в РАЗНЫХ местах работы: аннотация ↔ введение ↔ главы ↔ заключение. Для каждого расхождения приведи ОБЕ цитаты с их адресами. Особое внимание: цифры эксперимента, названия конфигураций/вариантов, статус гипотез (подтверждена/не подтверждена/inconclusive), TTL/имена/пороги.

## 4. Согласованность «задача → раскрытие → вывод»
Построй таблицу: каждая ЗАДАЧА из введения → где раскрыта (глава/раздел) → как подытожена в заключении. Флаг: задача без раскрытия; вывод без задачи; цель/гипотеза, не закрытая ни одной задачей; положение «на защиту» без подтверждающего текста.

## 5. Висячие утверждения и ссылки
- «Висячее» утверждение — сильный тезис без обоснования и без ссылки.
- Forward-ссылка «см. главу N», где обещанного нет, или результат противоположен обещанию.
- Перекрёстная ссылка на неверный номер раздела или на несуществующий класс/объект.
- Раздел/абзац, тематически не связанный с окружением.

## 6. Завершённость
Введение ставит вопрос → главы отвечают → заключение возвращается к вопросу. Флаг: «оборванные» линии (поднятая проблема без разрешения), отсутствие вывода по заявленному критерию.

## Метод
1. Извлеки текст (skill docx-review-extract).
2. Составь карту задача→глава→вывод.
3. Пройди по стыкам разделов и концам абзацев — отметь разрывы.
4. Собери все числа/термины-«дублёры» и сверь между разделами.

## Формат вывода
Таблица задача→раскрытие→вывод; список разрывов связности (цитата + место + предложенная связка); противоречия (цитата ↔ цитата); висячие утверждения/битые ссылки; таблица связности по разделам (0–5). Тяжесть 🔴/🟡/🟢.
