# Терминология и редактура: чек-лист нормоконтролёра

## 1. Единство терминологии (термины-дублёры)
Один объект — один термин по всей работе. Типичные дублёры в технических ВКР:
- «песочница» / `sandbox` / «сандбокс» / «изолированная среда»;
- «разбор» / «объяснение» / «обратная связь» / «фидбэк»;
- «конвейер» / «пайплайн» / `pipeline`;
- «попытка» / «решение» / `submission` / «сабмит»;
- «опрос» / `polling` / «пуллинг»;
- «страта» / «стратум».
Правило: русский термин — в связном тексте; латиница — только как имя модуля/класса/идентификатора (моноширинным). Транслиты (сандбокс, сабмит, пуллинг) недопустимы. Перечисли каждый дублёр с местами и рекомендуй единый вариант.

## 2. Аббревиатуры (ГОСТ Р 7.0.12)
- Каждая авторская аббревиатура расшифровывается при ПЕРВОМ употреблении: «…(далее — ВКР)».
- Сверь перечень сокращений с текстом: (а) используется, но НЕ внесено в перечень → добавить; (б) внесено, но НЕ встречается в тексте → удалить (перечень содержит только фактически используемые).
- В заголовках глав и параграфов аббревиатуры не допускаются.

## 3. Неоправданные англицизмы/латиница
Флаг: латиница/калька там, где есть устоявшийся русский термин (fallback→резервный путь, feedback→обратная связь). Оставлять латиницей допустимо только имена кода (`verdict-cap`, `fallback` как code-path) — единообразно. Проверь единообразие форм (harden- vs hardening-, чек- vs CHECK-).

## 4. Орфография и пунктуация
- Рассогласование падежа/числа/рода («конфирматорный эксперимента» → «конфирматорного эксперимента»).
- Единообразие написания: «хеш» (не «хэш»), «ё/е» по всей работе единообразно, бренды единообразно (e-olymp).
- Битые/выпавшие фрагменты («как -прогон обнаружил»), двойные пробелы, висячие дефисы.
- Тире: в подписях «Рисунок N – Название», «Таблица N – Название» (короткое тире с пробелами).

## Метод
Извлеки текст (skill docx-review-extract). Для дублёров — grep по всем вариантам термина с подсчётом. Для аббревиатур — сопоставь множество встречающихся в тексте с перечнем сокращений.

## Формат вывода
Термины-дублёры (термин → варианты → места → рекомендуемый единый); аббревиатуры (не расшифрованные / не в перечне / лишние); неоправданные англицизмы; орфография/пунктуация (цитаты). Каждая правка конкретна. Тяжесть 🔴/🟡/🟢.
