# Demo script — 5-минутное видео для защиты

Запасной артефакт на случай rate-limit GigaChat / отсутствия сети в зале защиты.
Цель: показать end-to-end что нейро-символический гибрид (B2) реально клампит
оценку при STUB-решении, и что инъекции отбиты.

Запись: QuickTime (Cmd+Shift+5) или OBS. Разрешение 1920×1080, fps 30.

## Сцены и таймкоды

### 00:00–00:25 — Заставка и интро (25 c)

Голос: «Дипломный проект — автоматизированная проверка задач по программированию
с применением ИИ. Я покажу за пять минут три вещи: что система делает, как она
защищена от prompt-injection из кода студента, и какие результаты эксперимента
B1 vs B2.»

Экран: terminal в полном экране, рабочий каталог `aidar_diplom`.

### 00:25–01:10 — Структура и тесты (45 c)

```bash
git log --oneline 8b272d7..11a867b
tree ai-analyzer/src/main/kotlin/ru/aianalyzer -L 2
./gradlew :ai-analyzer:test
```

Голос: «Семь коммитов, шесть фаз — hardening, JSON-schema, AST-гибрид, prompt
engineering, датасет, runner. 64 теста зелёные.»

Подчеркнуть в выводе строку `BUILD SUCCESSFUL` (highlight cursor).

### 01:10–01:55 — Threat model + 6 векторов (45 c)

```bash
cat ai-analyzer/THREAT_MODEL.md | head -50
```

Голос: «Шесть векторов prompt-injection из угрозной модели: прямые инструкции
в комментариях, Unicode-маскировка, role-confusion токены, JSON-injection,
HTML/markdown в выходе, переполнение по токенам. Для каждого — пример атаки,
митигация, остаточный риск.»

Промотать таблицу закрытости.

### 01:55–02:45 — Генерация датасета (50 c)

```bash
python3 experiment/generate_dataset.py
ls experiment/dataset/wrong/two-sum/
cat experiment/dataset/wrong/two-sum/04.json
```

Голос: «Датасет: 30 задач, 180 ошибочных решений (по шесть на задачу — WA, TLE,
RTE, STUB, STYLE, SECURITY), плюс 15 атак. Генератор детерминированный —
воспроизводимый артефакт. Здесь решение Two Sum со заглушкой `return new int[]{0,0}`
— STUB-категория.»

### 02:45–04:00 — Прогон эксперимента (1m 15s)

```bash
./gradlew :ai-analyzer:runExperiment --args="--variant=all --mode=mock"
```

Голос (поверх логов прогона): «Runner поднимает три варианта: B1 — GigaChat
zero-shot, B1f — GigaChat few-shot, B2 — нейро-символический AST-гибрид. Прогон
195 элементов на каждый вариант = 585 вызовов. Mock-режим, потому что без ключа
GigaChat. Real-режим включается автоматически при наличии env-переменной.»

Когда в логе мелькнёт строка `AstHybridAnalyzer: suspiciousReturnsConstant=true,
clamping codeQuality 65 → 60` — pause/replay:

Голос: «Вот главный empirical-результат. AST-эвристика обнаружила, что метод
возвращает константу. LLM (mock в этом случае) поставил 65. Symbolic clamp
поверх LLM понизил до 60. Это второй слой защиты от ложно завышенной оценки —
ровно то, что обещано в главе 4 записки.»

### 04:00–04:40 — SUMMARY и таблица B1 vs B2 (40 c)

```bash
cat experiment/results/SUMMARY.md
```

Голос: «Сводная таблица. Структурная валидность ответов 0.99 на B1/B1f, 1.00 на
B2. Injection success rate — ноль во всех трёх вариантах: все 45 атак
(15 × 3) отбиты. По категориям видно, что AST-гибрид даёт нижнюю оценку на
STYLE-кейсах — потому что AST видит структурные смелы, которые LLM иногда
прощает.»

### 04:40–05:00 — Артефакты для записки (20 c)

```bash
ls ai-analyzer/*.md
```

Голос: «Артефакты: THREAT_MODEL.md, PROMPT_DESIGN.md, DIFFERENTIAL_REVIEW.md,
SUMMARY.md от semgrep, INSECURE_DEFAULTS.md. Всё это материал для глав 3 и 4
записки. Спасибо.»

## Правила записи

- Шрифт терминала ≥ 18pt (видно на проекторе).
- Цветовая схема: тёмный фон, светлый текст (контраст для слайдов).
- Звук: голос микрофона, без музыки.
- Длина: 5:00 ровно. При перерасходе — сжимать сцены 3-4.
- Не показывать секреты в env (`echo $GIGACHAT_AUTH_KEY` не делать).
